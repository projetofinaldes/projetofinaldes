🐾 AdotePet — Site de Adoção de Animais

📌 Sobre o projeto
O AdotePet é um site desenvolvido para facilitar a adoção responsável de animais, conectando pessoas interessadas em adotar cães e gatos a protetores independentes e organizações de proteção animal.
A plataforma permite visualizar animais disponíveis para adoção, consultar suas informações e entrar em contato com os responsáveis por meio do WhatsApp.
O projeto busca incentivar a adoção responsável, facilitar a divulgação de animais e centralizar as informações em um único lugar.

🎯 Objetivos
Facilitar o encontro entre animais disponíveis e possíveis adotantes.
Divulgar informações e fotos dos animais.
Permitir o contato direto com os responsáveis por meio do WhatsApp.
Organizar os cadastros de animais e usuários.
Registrar e acompanhar solicitações de adoção.
Oferecer uma interface simples, intuitiva e responsiva.

⚙️ Funcionalidades
Página inicial do site.
Estrutura para exibição dos animais disponíveis.
Cadastro e login de usuários.
Cadastro, edição e remoção de animais.
Filtros por espécie, idade e porte.
Integração com WhatsApp para contato com os responsáveis.
Banco de dados para armazenar as informações.
Formulário de interesse em adoção.
Acompanhamento do status das solicitações.
Painel administrativo para gerenciamento dos cadastros.
Layout responsivo para computadores, tablets e celulares.
Observação: os itens marcados como concluídos devem ser atualizados conforme as funcionalidades forem realmente implementadas.

🛠️ Tecnologias utilizadas
HTML5: estrutura das páginas.
CSS3: estilização e responsividade.
JavaScript: interatividade e comunicação com o servidor.
Node.js: execução do back-end.
Express: criação das rotas e da API.
PostgreSQL: armazenamento dos dados.
Git e GitHub: versionamento e compartilhamento do código.

HTML: cria as páginas e os formulários.
CSS: define as cores, os tamanhos, o posicionamento e o visual.
JavaScript: faz os botões funcionarem, permite filtrar os animais e prepara o envio de informações.
Back-end: recebe e processa informações enviadas pelo site.
Banco de dados: guarda os animais cadastrados e, futuramente, os usuários e as solicitações de adoção.
WhatsApp: permite que a pessoa interessada entre em contato com o responsável pelo animal.
